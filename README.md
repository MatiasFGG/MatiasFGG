## Proyectos

### StockGuard PyME


Aplicación web de gestión comercial e inventario para pequeños negocios, desarrollada como proyecto personal.

El sistema utiliza React y TypeScript en el frontend, FastAPI en el backend y PostgreSQL como base de datos, con Docker para la gestión del entorno.

Durante su desarrollo he trabajado con autenticación mediante JWT, control de acceso por roles, operaciones CRUD, gestión de productos, categorías, proveedores e inventario, además de la comunicación entre frontend y backend mediante APIs REST.

Este proyecto me ha permitido adquirir experiencia práctica en la integración de diferentes tecnologías y en la organización de una aplicación con componentes separados.
